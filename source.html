Core Postulates (Public Layer)

P1 — Code-First Principle

Observable phenomena (physical, biological, informational, cognitive) are not primary causes. They are the outward record of deeper rule execution.

P2 — Finite Primitive Alphabet

The universe admits a finite set of primitive symbols (an “alphabet”). Higher structures arise by composition under immutable operators.

P3 — Immutable Generative Operators

Reality is produced by a constrained set of generative rules whose execution yields multi-layer structures and events.

P4 — Execution Trace View

“Event” is an output boundary. Causality is treated as rule-ordered generation, not merely prior-state mechanics.
