Constraint Claims (Public Layer)

C1 — Compression Bound

Any sufficiently rich world must admit bounded compressibility at the rule layer: complex observables arise from compact generative descriptions.

C2 — Alphabetic Bottleneck

If the primitive alphabet is finite, then all higher-level diversity is constrained by permissible compositions. This yields measurable “structure ceilings”.

C3 — One-Way Execution

Execution produces traces; traces do not uniquely reconstruct the full generator. This is an information-theoretic irreversibility, not a narrative claim.

C4 — Cross-Domain Invariants

Shared invariants are expected across physics / biology / computation when they are downstream of the same operator family.

Falsifiability Boundary (Minimal)

If no cross-domain invariants exist under any measurable operator class,
the claimed generative unity collapses.
