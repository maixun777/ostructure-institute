# CSOC × USC — Public Signal Nodes

This document records a set of public structural statements.
It does not introduce a project, theory, or proposal.

No interpretation is provided.
No discussion is expected.

---

## Public Node #1 — Code-First Execution

Events are not primary causes.  
They are execution traces of deeper generative rules.

If no rule-level operators can explain cross-domain regularities,  
this structure collapses.

---

## Public Node #2 — Finite Alphabet Constraint

A finite primitive alphabet constrains all higher-level diversity.  
Complexity emerges through composition, not expansion of primitives.

If unlimited novelty requires unlimited primitives,  
this structure collapses.

---

## Public Node #3 — Irreversibility of Traces

Execution traces do not uniquely reconstruct their generators.  
Irreversibility is structural, not historical.

If full reconstruction from events is always possible,  
this structure collapses.

---

## Public Node #4 — Cross-Domain Structural Invariants

Physics, biology, and computation share invariants  
when downstream of the same operator family.

If no invariant survives cross-domain projection,  
this structure collapses.

---

## Public Node #5 — Civilizational Fork

Recognition of code-first generation forces  
a shift from event narratives to operator identification.

If civilization can progress without this shift,  
this structure collapses.
